## Revisão

Pull Requests de programação devem ser revisados preferencialmente pelo outro programador.

Exemplo:

- Daniel implementa → Guilherme revisa;
- Guilherme implementa → Daniel revisa.

Mudanças que afetem sistemas de responsabilidade do outro programador devem ser alinhadas antes do merge.

Não é necessário que toda a equipe revise todos os Pull Requests.
